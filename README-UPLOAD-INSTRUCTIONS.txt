RANKERSBOARD DYNAMIC TEST PAGES

Upload every HTML file in this ZIP to the ROOT of your existing GitHub repository.
Do not put them in a subfolder. Do not replace index.html, mock-test.html, supabase-client.js,
admin-dashboard.html, or candidate-dashboard.html.

Included:
- SSC CGL 2024 and 2026 year landing pages plus complete/Maths/Reasoning/English/GK pages
- SSC CGL 2025 complete/Maths/Reasoning/English/GK pages (these replace the linked destinations)
- SSC CHSL, CPO, GD, MTS, Selection Post category pages

All test pages:
- Require candidate login
- Load only published tests from Supabase rb_tests
- Match tests to rb_exam_categories by category name
- Filter subject pages by subject/section text
- Link Start Test to mock-test.html?test_id=...
- Display test title, subject/section, duration, marks and negative marks

IMPORTANT:
The category name in Admin Dashboard must match the category used by the page:
SSC CGL 2024, SSC CGL 2025, SSC CGL 2026, SSC CHSL, SSC CPO, SSC GD,
SSC MTS, SSC Selection Post.
If you use different category names, rename/create matching categories in Admin Dashboard
or tell us the exact names so the pages can be adjusted.
